AI Email Assistant is an open-source, early-stage developer project exploring AI-assisted email understanding and response generation.

Python & FastAPI

SQLite & SQLAlchemy

Vanilla JavaScript & CSS

Clean, framework-free frontend

Anthropic Claude API

AI-powered language model integration

Project Status: Early Development
